# 基础编辑

## 音符与事件

音符栏负责 note（Tap）、wipe（Slide）和 hold。x、w、lpos、rpos 四栏负责轨道中心、宽度、左边和右边。编辑栏位于预览区右侧。

| 鼠标位置 | 按键 | 结果 |
| --- | --- | --- |
| 音符栏 | `Q` / `W` | note / wipe |
| 音符栏 | 两次 `E` | hold 头部与尾部 |
| 任意事件栏 | 两次 `E` | 对应属性的事件起点与终点 |
| 任意事件栏 | 两次 `T` | [事件组引用](/doc/事件组) |
| 对象附近 | `D` | 删除 |

长条和事件的终点要晚于起点。点击对象后可在侧边栏修改；事件可用缓动或贝塞尔曲线，贝塞尔填写两个内部控制点的四个坐标数。

## 选择、批量操作和历史

右键点击对象可加入或移出复制表；拖动左键框选并用 Shift 确认。`Ctrl + C/X/V` 复制、剪切、粘贴，`Escape` 清空选择。

demo 来源的普通粘贴和删除主要处理音符，使用 `Ctrl + A + V` / `Ctrl + A + D` 包含事件。edit 来源的事件选择按编辑区规则处理，详见[完整手册](/doc/说明文档#剪贴板)。

`Ctrl + Z/Y` 撤销和重做。侧边栏的“操作历史”可查看每次修改和时间范围、点击跳转；撤销后再操作保留原分支，可在“所有分支”中找回。切换谱面清空历史，重新启动不会恢复历史树。

## 标签页与轨道

顶部 `+` 添加标签页，可分别选择轨道并开关五种栏。标签页按钮不必先聚焦就能使用。切回单标签时，标签页复制表自动转换为 demo 来源的复制表。

侧边栏“轨道”的第一行可切换或编辑当前轨道，筛选可按位置范围、名称和设置项。滚轮在轨道列表中改变滚动条，在筛选下拉框中只滚动下拉框。

## 设置和保存

设置里可切换昼夜模式、波形图、声纹图和改键。改键时点击动作，按下组合键，松开所有按键后点击弹窗确认；立即保存到 `users/key.json`。

`Ctrl + S` 保存当前谱面。自动保存开启时每 60 秒留一份副本，演示模式期间暂停自动保存。失败补救和恢复方法见[更新指南](/doc/更新指南)。主题图片设置见[主题自定义](/doc/主题自定义)。
