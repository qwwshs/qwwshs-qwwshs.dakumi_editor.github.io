# 更新、备份与恢复

## 更新程序

1. 退出编辑器，备份程序基础目录的整个 `users/` 文件夹。
2. 另存外部 `plugins/` 和 `defaultBezier.txt` 等自行修改的文件。
3. 下载并完整解压新发行包，保留配套运行库，避免把新旧动态库混用。
4. 将用户文件迁入新程序的对应目录，再打开歌曲和谱面检查。

文档描述当前开发分支；发行包的版本可能较旧。不要只凭文档有某项功能，就认为手中的发行包已经包含它。

## 哪些文件要保留

| 文件 | 内容 |
| --- | --- |
| `users/chart/` | 所有歌曲、背景和谱面，以及各谱面的 `.editToolData` |
| `users/settings.json` | 全局设置 |
| `users/key.json` | 改键表 |
| `users/ui/` | 主题配置和自定义图片 |
| `users/auto_save/` | 自动保存副本 |
| `users/export/` | 导出结果 |

编辑选项已按谱面保存，如 `chart.json.editToolData`；新文件不存在时自动创建，不再从一个全局编辑选项文件读取。操作历史不持久保存，切换谱面会清空。

## 保存失败与恢复

手动保存失败会显示原因；若 JSON 已生成，可选择复制到剪贴板。随后粘贴到文本文件并保存为 `.json`，留住当前内容。复制成功不等于原谱面保存成功，修复目录权限或路径后再保存。

自动保存开启后，每 60 秒在 `users/auto_save/` 留副本，演示模式期间不运行；失败写入日志。需要恢复时，先备份当前谱面，选择对应歌曲，再拖入所需副本核对。不要把自动保存当成唯一备份，也不要假定崩溃时一定能成功写盘。

## 从 0.5.0 之前迁移

旧版本使用 LÖVE 保存目录。先在旧程序用“目录”按钮找到文件并备份，再把歌曲和用户文件迁入新程序的 `users/`。`.d3` 通过拖入导入，会转换成 `.json`，不要只改扩展名。

音符皮肤现在位于 `users/ui/`：`note.png`、`wipe.png`、`holdHead.png`、`holdBody.png`、`holdTail.png`。打击音放在 `users/`，文件前缀为 `hit`。完整配置见[主题说明](/doc/主题自定义)。
