# 谱面信息与音乐对齐

进入编辑界面，在右侧侧边栏打开“谱面信息”，可修改曲名、谱面名、谱师、艺术家、offset 和 BPM 表。普通输入完成后点击页面的确认按钮应用；保存到磁盘仍使用 `Ctrl + S`。

## 节拍与 BPM

节拍由三个数字组成：整数部分、分子、分母。例如 `2, 1, 4` 是 2 又 1/4 拍，分母不能为 0。

BPM 表按节拍排序。用添加按钮加入变化点，删除按钮移除相应项；“线性渐变到下一项”表示 BPM 在两项之间逐渐改变。

## offset 的方向

offset 用毫秒填写。实际读取音乐的位置是“谱面秒数 − offset / 1000”：正数让音乐相对谱面晚开始，负数让音乐在谱面第 0 拍时已经播放了一段。

例如音乐开头有 240 ms 静音，要让第 0 拍对应静音之后的位置，可以填 `-240`。是否准确需结合波形和试听核对。

## 自动测量 BPM 与 offset

BPM 表上方的“测量 BPM 与 offset”会在后台分析音乐。完成后系统弹窗展示结果，并询问是否填入 offset 和第一项 BPM；其他 BPM 变化点不变。拒绝或关闭弹窗则不修改谱面。

测量只给出一个整体 BPM。offset 测的是开头静音长度，不是自动寻找歌曲第一拍；变速曲或开头没有静音的曲目仍需手动调整。结果可作为一条操作历史撤销。分析过程中切换谱面或音乐，旧结果会丢弃。

采用 LuaJIT 后台计算，不需要安装额外命令行工具。目前分析支持 2 秒到 30 分钟音频；特殊采样率会先转换。测量算法参考 [qwwshs/bpm](https://github.com/qwwshs/bpm)。

## 偏好与轨道属性

“偏好”中的 `x_offset` 和 `event_scale` 是编辑坐标的换算方式，不是音乐时间。默认偏移为 0、缩放为 100。轨道名称、父轨道、绘制顺序和边界在“轨道”中编辑；这些谱面修改都可以撤销。
