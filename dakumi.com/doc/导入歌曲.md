# 导入歌曲与谱面

## 新建歌曲

在选曲界面把音乐拖入窗口。支持 `wav`、`mp3`、`ogg`，会在 `users/chart/` 创建歌曲文件夹和默认空谱面。文件应使用与实际格式一致的后缀。

## 导入已有谱面和背景

先选中对应的歌曲，再拖入文件：

| 文件 | 用途 |
| --- | --- |
| `.json` | 导入 Dakumi JSON 谱面 |
| `.d3` | 导入旧版数据格式并转换为 JSON；不用手动改后缀 |
| `.jpg`、`.jpeg`、`.png` | 设置歌曲背景 |

旧 d3 仅解析数据表，不执行 Lua 代码。无法解析时检查文件是否是正确的旧谱面，不要用改后缀来掩盖格式问题。

导入后在菜单选择谱面并进入编辑。原始文件建议另外保留一份；从 `users/auto_save/` 导入副本时，也要先选择对应歌曲。

## 导入失败时

先确认格式与后缀，再查看 `users/log/` 日志。问题反馈时提供文件类型、版本和复现步骤；不要直接删除整首歌曲的文件夹，以免连同已有谱面一起丢失。用户数据位置与备份方法见[更新指南](/doc/更新指南)。
